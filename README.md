## About Me

I'm a **Full-Stack Developer** focused on building high-performance, real-time web applications with clean architecture, scalable modular code, and rigorous security standards.

I engineer solutions across the entire product lifecycle — from interactive 2D spatial interfaces and state machines on the frontend to high-throughput asynchronous APIs, database design, and cryptographic data protection on the backend.

* **Frontend Architecture:** Next.js 16 (App Router, Turbopack), React 19, TypeScript, Zustand, and Tailwind CSS.
* **Spatial & Interactive UIs:** 2D infinite canvases, draggable/resizable modular widgets, and algorithmic relation routing.
* **Real-Time Systems:** Full-duplex WebSockets for instant messaging, push notifications, and live presence synchronization.
* **Backend & Microservices:** Python (FastAPI, Asyncio), Node.js, Express, and RESTful architectures.
* **Databases & ORM:** PostgreSQL with SQLAlchemy 2.0 (Async Engine), Redis caching, and automated Alembic migrations.
* **Security & Cryptography:** Field-level AES-256 data encryption, Argon2 password hashing, and OAuth 2.0 with JWT token rotation.
* **Testing & Quality Assurance:** Comprehensive automated testing with Jest, React Testing Library, and Pytest.
